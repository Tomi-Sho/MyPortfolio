# MyPortfolio
Node.js / GraphQL バックエンドとレスポンシブWebデザインを組み合わせた、動的ポートフォリオサイトです。
スキルセットや制作実績のデータをGraphQL API経由で取得し、フロントエンドで動的にレンダリングを行っています。

---

## 特徴
- **動的コンテンツ描画**: GraphQL APIを利用し、製作品やスキルのデータをフロントエンドで動的に取得します。
- **スクロールアニメーション**: JavaScriptを利用し、スクロールアニメーションとフェードイン効果をつけました。

## 使用技術

### フロントエンド
- **HTML5 / CSS3**
- **JavaScript (ES6+)**
- **Font Awesome 6**

### バックエンド
- **Node.js**
- **GraphQL Yoga**

### 開発ツール
- **Git / GitHub**
- **Git Bash**
